# Token marks

Square, full-bleed tiles for `TokenIcon`. Each mark belongs to its owner; the background of a
round original is extended to the corners so it fits the square-cut tile.

| File | Token | Source |
| --- | --- | --- |
| `eth.svg` | ETH | Ethereum diamond, from `spothq/cryptocurrency-icons` (CC0) |
| `usdg.png` | USDG, Global Dollar (`0x5fc5360D0400a0Fd4f2af552ADD042D716F1d168` on Robinhood Chain) | CoinGecko token image |
| `nvda.svg` | NVDA, NVIDIA • Robinhood Token | NVIDIA mark, from Simple Icons (CC0) |
| `spcx.svg` | SPCX, SpaceX • Robinhood Token | SpaceX mark, from Simple Icons (CC0) |
| `spy.svg` | SPY, SPDR S&P 500 ETF Trust • Robinhood Token | SPDR wordmark as traced by TradingView's symbol logos |
| `pons.png` | PONS (`0x39dBED3a2bd333467115dE45665cC57F813C4571`) | DexScreener token image |
| `cashcat.png` | CASHCAT (`0x020bfC650A365f8BB26819deAAbF3E21291018b4`) | CoinGecko token image |

The three stock tokens share one official token icon (the Robinhood feather on lime). The company
marks are used here instead so the rows can be told apart; replace them with files cleared for use
before launch.
